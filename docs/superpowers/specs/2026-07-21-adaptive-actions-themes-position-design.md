# 提示词助手图标、主题与默认位置改进设计

日期：2026-07-21

状态：用户已确认

## 1. 目标

本次改动依次解决三个视觉问题：

1. 消除浅色主题中提示词卡片右侧“编辑 / 删除”按钮呈现为黑色块的问题。
2. 让提示词助手的所有主题敏感表面、文字、图标、边框与阴影完整适配 ChatGPT 的浅色和深色主题。
3. 在没有已保存拖动位置时，将悬浮入口默认放在网页右下角，距右侧和底部各 24px。

提示词 CRUD、插入逻辑、存储格式、拖动保存、面板自动避让和权限边界保持不变。

## 2. 根因

卡片操作按钮当前在 `content.css` 中使用硬编码的深色背景 `#202126` 和暗色文字 `#b7b8c1`。这些值没有随 `#phg-root` 的主题变量变化，因此浅色主题仍显示两块近黑色按钮。

此外，标题栏边框、关闭按钮、创建入口图标、箭头和部分阴影仍含主题敏感的硬编码颜色。虽然面板主体已经能识别 ChatGPT 的明暗主题，这些局部颜色会削弱整体一致性。

## 3. 方案选择

采用“完整主题变量化 + 内联 SVG 图标”方案：

- 把操作表面、操作图标、危险操作、标题栏边框、次级图标、焦点环和阴影归入语义变量。
- 在暗色默认值、ChatGPT 显式暗色、ChatGPT 显式浅色以及系统主题回退中提供完整取值。
- 继续使用 CSS 选择器跟随页面主题，不新增 MutationObserver 或其他 JavaScript 主题监听器。
- 编辑和删除使用本地代码创建的内联 SVG，不引入远程图片、第三方图标包或新权限。

不采用只修两个按钮的局部补丁，因为它会保留其他浅色主题违和；不采用 JavaScript 主题监听，因为现有根选择器已经能在主题切换时即时重新计算 CSS。

## 4. 卡片操作图标

卡片右侧操作从可见文字改为两个图标按钮：

- 编辑：铅笔轮廓图标。
- 删除：垃圾桶轮廓图标。
- SVG 使用 `currentColor`，颜色由主题变量和危险状态决定。
- 桌面精细指针下保持紧凑尺寸，并继续仅在卡片 `hover` 或 `focus-within` 时显示。
- 粗指针或无悬停设备下始终显示，交互区域至少为 44 × 44px。
- 每个按钮保留中文 `aria-label` 和 `title`，键盘焦点环清晰可见。
- 编辑和删除仍阻止事件冒泡，不得触发提示词插入。

浅色主题中，普通操作默认使用透明或浅灰表面，悬停时轻微加深；删除操作使用低饱和淡红表面和深红图标。深色主题使用低对比深灰表面和柔和红色危险态，但不得出现突兀的纯黑按钮块。

## 5. 明暗主题系统

主题继续限定在 `#phg-root`，避免污染 ChatGPT 页面。识别优先级保持如下：

1. `html.dark` 或 `html[data-theme="dark"]`。
2. `html.light` 或 `html[data-theme="light"]`。
3. 页面没有显式标记时，回退到 `prefers-color-scheme`。

新增或整理语义变量，至少覆盖：

- 普通操作按钮表面、悬停表面、边框和图标。
- 危险操作表面、悬停表面、边框和图标。
- 标题栏与页脚分隔线。
- 次级图标和关闭图标。
- 创建入口的加号块与箭头。
- 焦点环。
- 面板、状态提示、弹窗和悬浮入口的主题阴影。

主题切换必须即时更新，不刷新页面，不复制 ChatGPT 类名到扩展子树。现有 `color-scheme`、动画、减少动态效果和触控回退继续保留。

## 6. 悬浮入口默认位置

`clampFloatingPosition()` 在收到 `null` 或无有效坐标的位置时，以视口右下角为默认锚点。默认位置内缩量为 24px：

- `left = viewport.width - launcher.width - 24`
- `top = viewport.height - launcher.height - 24`

默认内缩量与拖动安全边界分开处理：默认坐标使用 24px，用户拖动和窗口缩放时的最小安全边界仍保持现有 12px。小视口下继续使用现有边界压缩规则，确保入口始终可见。页面已有保存位置时继续使用保存值；窗口尺寸变化后继续钳制到 12px 安全范围。面板仍根据可用空间选择上、下、左或右侧展开，在右下角默认位置通常优先向上展开。

本次改动不清除或迁移已有用户的拖动位置。

## 7. 测试与验收

按照测试驱动开发顺序增加回归覆盖：

1. 先断言编辑和删除按钮包含内联 SVG，并保留中文无障碍名称；当前文字按钮实现应使测试失败。
2. 断言操作按钮使用语义变量，样式中不再出现卡片操作按钮的硬编码 `#202126` 背景；当前样式应使测试失败。
3. 断言显式浅色、显式暗色以及系统回退都包含完整的操作和图标主题变量。
4. 断言空位置在 320 × 240 视口、48 × 48 入口下得到 `{ left: 248, top: 168 }`，即右侧和底部各 24px。
5. 保留越界钳制、拖动保存、面板避让、粗指针 44px 目标、键盘焦点和事件阻止测试。
6. 运行 `npm run verify`，要求语法检查和全部 Node 测试通过且无警告。

人工验收同时覆盖 ChatGPT 浅色、深色和系统主题：操作图标无黑块，文字与边框对比清楚；新安装或无保存位置时悬浮入口位于右下角；拖动并刷新后仍使用用户保存位置。

## 8. 文件范围

预计只修改：

- `ui.js`：创建铅笔和垃圾桶内联 SVG；把卡片操作按钮改为图标结构；新增 24px 默认内缩，同时保留 12px 拖动安全边界。
- `content.css`：补全主题变量并替换主题敏感硬编码；定义图标按钮状态。
- `tests/ui.test.js`：增加图标、主题和默认位置的红绿回归测试。
- `README.md`、`DEVELOPMENT.md`、`TEST_CHECKLIST.md`：同步用户行为、实现约束和人工检查项。

不修改存储层、提示词引擎、编辑器适配器或扩展权限。
