# README 仿写设计

日期：2026-07-21
状态：用户已确认

## 1. 目标

参考 [issacsmit/Prompt_Helper_Extension](https://github.com/issacsmit/Prompt_Helper_Extension) 的 README 信息结构和简洁语气，为 ChatGPT 版本提供一份适合公开仓库首页的中文 README。文档优先帮助普通用户快速理解、安装和使用扩展，同时给开发者保留必要的结构、数据和验证入口。

README 只描述当前仓库已经实现并可验证的行为，不照搬参考项目中仅适用于 Gemini、单文件实现或不同目录布局的说明。

## 2. 内容方案

采用与参考项目接近的章节顺序：

1. 项目名称和一句话简介。
2. 特性：提示词 CRUD、光标插入、占位符、可拖拽浮钮、明暗主题、自适应操作图标、键盘与减少动画支持、本地存储。
3. 安装：克隆或下载仓库、打开 Chrome 扩展管理页、启用开发者模式、加载当前仓库根目录、刷新 ChatGPT。
4. 使用：打开面板、新增提示词、使用占位符、点击卡片插入，以及编辑、删除和拖动入口。
5. 占位符：默认值、旧版兼容值、自定义值和历史规则。
6. 技术栈：Manifest V3、原生 JavaScript、原生 CSS、无构建和零运行依赖。
7. 目录结构：按当前多模块架构列出生产文件、图标、测试和开发文档。
8. 数据结构：列出三个 `chrome.storage.local` 键和单条提示词 JSON 示例。
9. 隐私与权限：说明仅有 `storage` 权限、不联网、不读取 API Key、不上传提示词或聊天内容、不自动发送。
10. 开发与验证：重载扩展、刷新页面、运行 `npm run verify`，并链接 `DEVELOPMENT.md` 与 `TEST_CHECKLIST.md`。

## 3. 呈现约束

- 使用中文为主，保留必要的 Chrome、ChatGPT、Manifest V3 和 API 标识。
- 保持参考 README 的短段落、项目符号和可复制步骤，不继续保留现有 README 中过细的实现说明。
- 不添加徽章、效果截图或商店安装入口，因为仓库目前没有对应的稳定资源。
- 不声明 MIT 或其他许可证，因为当前仓库没有 `LICENSE` 文件。
- 安装步骤必须选择包含 `manifest.json` 的仓库根目录，不能照搬参考项目的 `prompt-helper/` 子目录。
- 不承诺浏览器或页面尚未验证的能力；真实 ChatGPT 冒烟仍以 `TEST_CHECKLIST.md` 为准。

## 4. 验收

- README 章节结构与参考项目明显一致，但所有名称、链接、目录、命令和行为均对应本项目。
- 用户可在首页内完成“理解用途 → 手动安装 → 新增提示词 → 插入提示词”的完整路径。
- `manifest.json` 中的权限、站点范围、版本和脚本结构与 README 没有冲突。
- `package.json` 中列出的验证命令在 README 中可直接复制执行。
- Markdown 相对链接均指向仓库内真实文件。
