# ChatGPT 提示词助手「静默轨道」UI 改版设计

日期：2026-07-15

状态：用户已批准
范围：仅重构扩展界面结构、视觉与微交互，不改变提示词、存储或编辑器插入语义

## 1. 背景与目标

当前扩展功能完整，但界面呈现为通用管理表单：入口使用文字圆钮，面板头部拥挤，卡片操作始终可见，弹窗缺少稳定分区，整体视觉密度和状态反馈弱于参考的 Gemini 插件。

本次改版不复制 Gemini 的深蓝面板、星芒标志或虚线新增按钮，而是建立独立的「静默轨道」设计语言：

- 以 ChatGPT 的中性黑灰表面为环境基础。
- 蓝紫只用于入口、焦点、光轨和短暂反馈。
- 使用独立的“对话气泡 + 命令光标 + P”标志，不使用 Gemini 或 OpenAI 官方标志。
- 界面静止时小巧安静，交互发生时通过阴影、方向性展开和细窄光轨提供反馈。
- 动效有连续节拍，不堆叠无意义动画，不牺牲性能或可访问性。

## 2. 不变的功能契约

改版不得改变下列现有行为：

- 提示词新增、编辑、删除与点击插入。
- 默认 `【光标】`、旧版 `[光标]`、自定义占位符和历史记录。
- 插入前书签、当前位置插入、选区起点插入且不覆盖原文字。
- contenteditable/textarea 兼容、附件保留、SPA 重建适配。
- 浮动入口拖拽、位置持久化、视口边界限制和面板自动避让。
- Chrome 本地存储、失败回滚、跨标签页同步。
- Esc、焦点循环、焦点恢复、外部点击关闭和可见错误提示。
- 仅支持 `https://chatgpt.com/*`，权限仍只有 `storage`，不新增网络、后台或 AI 功能。

## 3. 视觉原则

### 3.1 安静优先

静止状态只展示完成任务所需的信息。入口不持续呼吸或闪烁；提示词卡片默认不显示编辑、删除；面板不会使用高饱和大面积底色。

### 3.2 反馈有因有果

阴影、光晕和位移只响应悬停、打开、按下、拖拽或聚焦。用户离开状态后，界面快速回到安静状态。

### 3.3 空间连续性

面板以浮动入口为变换原点，从入口方向展开和收束。弹窗从页面中心建立独立层级，不能看起来像面板尺寸突然放大。

### 3.4 品牌独立

自定义标志表达“提示词对话工具”，但不使用官方 Blossom，也不设计成 Gemini 星芒。蓝紫渐变是扩展自身的识别色，而不是对某一站点品牌的复制。

## 4. 设计系统

### 4.1 色彩

暗色主题核心变量：

- 页面外表面：`#18191c`
- 面板表面：`#1f2024`（约 98% 不透明）
- 卡片表面：`#232429`
- 卡片悬停：`#27282e`
- 主文字：`#f4f4f6`
- 次文字：`#8d8e97`
- 普通边框：`#34353e`
- 强调边框：`#464853`
- 入口渐变：`#6c79f4 → #795fe5 → #8a5dda`
- 光轨：`#8b8df4 → #9e78e7`
- 危险文字：`#ffaaa7`

亮色主题使用相同语义而非简单反色：白色面板、微暖灰列表、深石墨文字、低饱和靛蓝强调色和更轻的阴影。

主题优先跟随 ChatGPT 页面主题；系统 `prefers-color-scheme` 仅作为页面主题无法识别时的回退。页面主题切换后，扩展应即时更新，无需刷新。

### 4.2 圆角与阴影

- 浮动入口：圆形，52 px。
- 面板：14 px 圆角。
- 提示词卡片：10 px 圆角。
- 常规控件：8–9 px 圆角。
- 弹窗：14 px 圆角。
- 静止阴影低对比；悬停入口通过独立伪元素的透明度和缩放形成扩散光晕，避免持续插值大面积 `box-shadow`。

### 4.3 字体与密度

- 沿用系统 UI 字体，不下载字体。
- 面板宽度约 348 px；小视口下最大宽度为 `calc(100vw - 24px)`。
- 桌面按钮采用 28–38 px 视觉高度；粗指针设备将交互目标扩展至至少 44 px。
- 卡片预览保持单行，优先提高可浏览数量。

## 5. 组件设计

### 5.1 浮动入口

结构：圆形渐变底、自定义线性 SVG 标志、右下角小型 `P` 标识、内部顶部高光。

状态：

- 静止：轻量下投影，无持续动画。
- 悬停：上浮 3 px、缩放至约 1.035；外围紫灰光晕缓入；命令光标横移约 1.5 px。
- 按下：快速缩放至约 0.97，阴影收紧。
- 打开：保持约 1.015 的轻微抬升，弱光晕维持，以表达入口与面板的连接。
- 拖拽：使用抓取光标，取消悬停上浮；投影收紧并显示低对比外环；释放后用短曲线回稳。
- 键盘聚焦：使用清晰、非发光过度的双层焦点环。

入口的 SVG 必须内联在扩展代码中，不引用远程资源。

### 5.2 提示词面板

面板分为三个稳定区域：

1. 标题栏：轨道圆点标识、标题“提示词助手”、Esc 提示或关闭图标。
2. 列表区：微深背景和紧凑提示词卡片。
3. 底部入口：独立的“创建提示词”行，使用小型加号方块和右箭头，不复制 Gemini 的全宽虚线按钮。

面板顶部包含一条很弱的水平渐变高光，作为「静默轨道」独有细节。高光不能抢过标题和内容。

### 5.3 提示词卡片

默认只显示名称和单行正文预览。点击卡片主体仍直接插入提示词。

- 精细指针设备：编辑、删除默认 `opacity: 0`，当前卡片 `hover` 或 `focus-within` 时淡入并从右侧移动约 7 px；同一时间只有当前卡片显示操作。
- 卡片进入交互状态时，左侧 2 px 蓝紫光轨从中心向上下生长；边框和背景轻微增强，但卡片本身不再上下跳动，避免列表抖动。
- 键盘聚焦与鼠标悬停提供等价状态。
- 粗指针设备没有可靠悬停，编辑和删除必须保持可见，交互目标至少 44 px。
- 编辑、删除按钮必须阻止事件冒泡，不能触发提示词插入。

### 5.4 添加/编辑弹窗

弹窗宽度约 410 px，采用标题、可滚动正文、底部操作三段式；每段之间有细边框。

- 名称输入、提示词正文、光标占位符和历史标签保持现有字段与数据流。
- 默认正文区域足够显示多行内容，但不使弹窗占满页面。
- 聚焦态使用低透明靛蓝双层边框。
- 历史占位符呈紧凑胶囊标签；标签删除仍可访问。
- 取消为中性按钮，保存为实色靛蓝按钮；删除确认使用独立小弹窗，不把危险操作放入编辑表单主路径。
- 遮罩使用中性半透明黑色，可有极轻背景压暗，但不使用重度模糊。

### 5.5 状态提示

- 存储、编辑器缺失或插入失败继续显示可见中文错误。
- 错误提示固定在面板/入口附近，使用深色表面和细危险色边框，不使用全屏通知。
- 成功插入默认通过“面板收束 + 编辑器重新聚焦”表达，不额外弹出成功 Toast。

## 6. 动效规范

采用连续而非同时发生的节拍：

- `0 ms`：入口立即响应。
- `0–165 ms`：面板透明度建立轮廓。
- `0–270 ms`：面板从入口方向完成位移和缩放，曲线为接近 `cubic-bezier(.16, 1, .3, 1)` 的自然减速。
- `55 / 82 / 109 ms`：前三条可见卡片以约 27 ms 的轻错峰进入，移动距离不超过 5 px。
- `130 ms`：底部创建入口开始落位。
- 关闭在约 175 ms 内快速反向收束，不对卡片逐条做离场动画。
- 卡片光轨约 230 ms 生长；操作按钮在 25 ms 后接续，约 170–235 ms 完成。
- 悬停和焦点过渡约 160–220 ms。

性能约束：

- 主展开/收束只动画 `transform` 和 `opacity`。
- 不对面板使用 `filter: blur()` 动画。
- 通过伪元素淡入实现大范围光晕，减少大阴影连续插值。
- 仅在短暂动画元素上使用 `will-change`。
- `prefers-reduced-motion: reduce` 时关闭错峰、缩放、位移和光轨生长，仅保留必要的即时显隐与焦点反馈。

## 7. DOM 与状态实现

- 浮动入口继续使用原生 `button`，保留 Pointer Events 拖拽逻辑。
- 面板打开/关闭不再直接依赖 `hidden`，因为 `hidden` 无法播放关闭动画。改用 `data-phg-state="open|closed"`、`aria-hidden`、`visibility` 和 `pointer-events`；关闭动画结束后再进入不可交互状态。
- 弹窗仍使用真实 `role="dialog"`、`aria-modal="true"`、焦点循环和 Esc。
- UI 结构继续完全位于 `#phg-root` 下，所有类名保持 `phg-` 前缀，避免污染 ChatGPT。
- 用户内容继续只通过 `textContent` 或表单 `value` 写入，不进入 `innerHTML`。
- ChatGPT SPA 观察器继续确保唯一 UI 实例。

## 8. 响应式与可访问性

- 面板和弹窗必须始终限制在视口内，缩放后重新校正入口和面板位置。
- `pointer: coarse` 下始终展示卡片操作，并扩大操作目标。
- 所有可交互元素保留 `focus-visible`。
- 键盘用户可打开面板、遍历提示词、插入、编辑和删除。
- 颜色对比度需满足常规正文和控件辨识要求；不能仅靠颜色表达危险或焦点。
- 动画不能改变已捕获的编辑器书签，也不能在面板关闭前错误恢复焦点。

## 9. 实施边界

主要修改：

- `ui.js`：入口内联 SVG、面板三段结构、动画状态类、卡片操作显隐所需结构和主题状态同步。
- `content.css`：完整视觉变量、亮暗主题、组件样式、交互与动效。
- `tests/ui.test.js`、`tests/controller.test.js`、`tests/file-integrity.test.js`：更新结构断言和新增交互回归。
- 本地 fixture：用于真实浏览器检查悬停、打开/关闭、主题、粗指针回退和减少动画。

除非测试证明必要，不修改提示词引擎、存储层或编辑器适配器。

## 10. 验收标准

- 浮动入口不再显示“提示词”文字，使用批准的自定义标志与蓝紫渐变。
- 悬停入口可见柔和阴影、光晕和轻微上浮，离开后平滑恢复。
- 面板具有标题、列表、创建入口三段结构，并从入口方向流畅展开/收束。
- 桌面端卡片操作只在当前卡片悬停或聚焦时显示；触屏端始终可操作。
- 弹窗紧凑、分区明确，历史占位符可用。
- ChatGPT 明暗主题切换后扩展同步更新。
- `prefers-reduced-motion` 下无非必要动画。
- 所有现有功能测试继续通过，并新增视觉状态的结构与静态守卫。
- 本地浏览器 fixture 验证悬停、面板动画、拖拽、CRUD、插入、SPA 重建、附件保留和控制台无错误。

## 11. 已决策事项

- 采用「静默轨道」而非复刻 Gemini。
- 采用自定义提示词标志，不使用 OpenAI/Gemini 官方标志。
- 采用蓝紫入口与 ChatGPT 中性表面。
- 采用桌面悬停/聚焦显示操作、触屏始终显示操作。
- 采用流畅版连续节拍，不使用模糊动画。
